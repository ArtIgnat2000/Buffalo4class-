# Бизон — сайт-презентация

Интерактивная презентация на русском языке из трёх слайдов: краткое определение, интересные факты и история спасения бизонов.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

Переключать слайды можно стрелками на экране, клавишами клавиатуры, колёсиком мыши или свайпом.
